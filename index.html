標案追蹤

尚未檢查

機關名稱可以只打一部分，從下拉清單挑選最準。點標案名稱看完整資料；「公開閱覽」的案子可以按「正式上網時通知我」。

我的公司

標案推薦會用這家公司的歷次投標紀錄，找出最近類似的公開閱覽和招標案。可以隨時換成其他公司。

在手機、平板、電腦之間同步

每台裝置的追蹤清單和公司設定分開存。最快：在有最新資料的那台按「顯示同步 QR Code」，用另一台手機的相機掃描，打開網頁後選「取代」或「合併」。也可以按「複製同步連結」用 LINE 傳給自己。

其他方式：

選填：歐噴 API token

建議填寫：免費 API 沒填 token 時查詢速度受限，追蹤項目多時更新會比較慢或失敗。到 data.openfun.tw 免費申請。

資料來源：g0v／歐噴 pcc-api，收集自政府電子採購網，每日更新，可能比採購網晚幾小時到一天；正式投標請以政府電子採購網為準。個人、非營利使用。
